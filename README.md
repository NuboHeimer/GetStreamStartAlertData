# SetAnnounceDataVariable
Функция проверяет наличие глобальной переменной stringAnnounceData и если она отсутствует или пуста, то пытается сохранить в неё данные из файла, находящегося по пути pathToAnnounceData.
Можно повесить выполнение на триггер запуска стримербота или на любой удобный вам триггер.
Важно отметить, что эта функция вызывается из всех Get функций, чтобы не было необходимости вызывать её отдельно.

# UnsetAnnounceDataToVariable
Очищает глобальную переменную stringAnnounceData.
Эту функцию необходимо вызывать вручную в нужных вам точках. Либо после отправки всех данных анонса.

Остальные функции будут описаны позже.
